## Selected product

### [Totteta](https://totteta.app/)

A free, privacy-conscious macOS application for recording, transcription, local speaker labeling, and AI-assisted meeting notes.

- Records microphone and system audio from apps such as Zoom, Google Meet, Microsoft Teams, and YouTube
- Uses macOS speech recognition for transcription
- Performs speaker labeling locally, without sending recorded audio or transcripts to an external service
- Supports AI-assisted editing and meeting notes through user-configured APIs or Codex / Claude Code
